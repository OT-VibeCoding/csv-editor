# CSVエディタ

Windows 11 用の、シンプルで軽い CSV 編集ソフトです。
Windows に最初から入っている .NET Framework 4.8 だけで動くので、追加でインストールするものはありません(exe は約 70KB)。

## ダウンロード

**[CsvEditor.zip をダウンロード](https://github.com/OT-VibeCoding/csv-editor/raw/main/dist/CsvEditor.zip)**

ダウンロードした zip を展開し、中の `CsvEditor.exe` を起動してください。

- zip を開いたまま exe を実行せず、右クリック →「すべて展開」してから起動してください。
- 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。

### 自分でビルドする場合

このリポジトリの `CsvEditor.cs` と `build.bat` を同じフォルダに置き、`build.bat` をダブルクリックしてください。Windows 標準の C# コンパイラで `CsvEditor.exe` が作られます(インストール不要、数十秒で終わります)。

## 主な機能

- 開く / 上書き保存 / 名前を付けて保存 / 最近使ったファイル / ドラッグ&ドロップで開く(ショートカットにも対応)
- 元に戻す / やり直し(何段階でも。入力・貼り付け・行列操作・並べ替えすべてが対象)
- 切り取り / コピー / 貼り付け(Excel との間でもコピペできます)、1 つの値を選択範囲にまとめて貼り付け
- 下方向へコピー(Ctrl+D)/ 右方向へコピー(Ctrl+R)
- 行・列の挿入と削除、昇順 / 降順の並べ替え(数値は数値として比較)
- 1 行目を見出しとして固定、列幅の自動調整
- 検索 / 置換 / すべて置換 / 指定セルへ移動
- 選択範囲の個数・合計・平均をステータスバーに表示
- 文字コードの自動判別(UTF-8 / UTF-8 BOM 付き / Shift_JIS / UTF-16)、保存時の文字コード変更
- 区切り文字(カンマ / タブ / セミコロン)と改行コード(CRLF / LF)の切り替え
- 表示設定:文字サイズ、フォント、セルからはみ出す文字の扱い(折り返す / はみ出す / 切り詰める)

## ショートカット

| キー | 動作 |
|---|---|
| Ctrl+N / Ctrl+O / Ctrl+S | 新規 / 開く / 上書き保存 |
| Ctrl+Shift+S | 名前を付けて保存 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+X / Ctrl+C / Ctrl+V | 切り取り / コピー / 貼り付け |
| Del | 削除 |
| Ctrl+A | すべて選択 |
| Ctrl+D / Ctrl+R | 下方向へコピー / 右方向へコピー |
| Ctrl+F / F3 / Ctrl+H | 検索 / 次を検索 / 置換 |
| Ctrl+G | 指定のセルへ移動 |
| Ctrl++ / Ctrl+- | 行の挿入 / 行の削除 |
| Ctrl+; / Ctrl+Shift+- / Ctrl+0 | 文字を大きく / 小さく / 標準サイズ |
| Ctrl+マウスホイール | 拡大・縮小 |
| Enter / Shift+Enter | 確定して下へ / 確定して上へ |
| Tab / Shift+Tab | 右へ / 左へ |
| F2 | セルを編集 |
| F1 | ヘルプ |

### セル入力中の矢印キー(Excel と同じ 2 つのモード)

| モード | 始め方 | 矢印キーの動き |
|---|---|---|
| 入力モード | セルを選んでそのまま文字を打ち始める | 入力を確定して、隣のセルへ移動 |
| 編集モード | F2 / ダブルクリック / 入力中にセル内をクリック | セルの中で文字を移動(← → は 1 文字ずつ、↑ で先頭、↓ で末尾) |

- 入力モード中に F2 を押すと、編集モードに切り替わります。
- 編集モードでは、文字の端に来ても隣のセルへは移動しません。Shift を押しながらだと選択します。
- Enter / Shift+Enter / Tab / Shift+Tab は、どちらのモードでも確定してセルを移動します。

## 表示設定

「表示」メニューかツールバーから変更できます。

- **文字サイズ**:A+ / A- ボタン、Ctrl+マウスホイール、または 8〜24pt から選択
- **セルからはみ出す文字**
  - 折り返す:セルの幅で改行し、行の高さが自動で伸びます
  - はみ出す:右隣が空のセルなら、そこまで文字を表示します(Excel と同じ)
  - 切り詰める:セルに収まらない部分を「…」で省略します

表示設定はソフト側(`%APPDATA%\SimpleCsvEditor\settings.ini`)に保存され、CSV ファイルの中身には影響しません。アンインストールは exe とこのフォルダを削除するだけです。
